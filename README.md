## Project Purpose & Overview

The **Trading Platform** is engineered to deliver a fast, intuitive, and reliable interface for financial traders. By leveraging modern frontend technologies, the application ensures minimal latency in rendering market updates, interactive charts, and transaction states. 

### Key Features (Planned & Current)
* **Real-time Data Streaming:** Optimized rendering pipelines for live ticker and order book updates.
* **Interactive Charting:** Clean visualization of historical and real-time market trends.
* **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewports.
* **Developer-Friendly Tooling:** Fast hot-module replacement (HMR) and strict linting configurations to maintain code quality.

## Getting Started & Installation

Follow these instructions to set up and run the project locally.

### Prerequisites

Ensure you have the following installed on your local machine:
* **Node.js** (v18.x or higher recommended)
* **npm** (v9.x or higher) or **yarn** / **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/fawaztanigbola/trading-platform.git
   cd trading-platform
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Application

To start the local development server:

```bash
npm run dev
```

Once started, the terminal will display the local server URL (typically `http://localhost:5173/`). Open this URL in your browser to view the application.

## Usage & Scripts

Inside the `frontend/` directory, you can run the following commands:

* **`npm run dev`**: Starts the Vite development server with Hot Module Replacement (HMR).
* **`npm run build`**: Compiles and optimizes the application for production. The output is generated in the `dist/` directory.
* **`npm run preview`**: Locally previews the production build generated by the build script.
* **`npm run lint`**: Runs ESLint to analyze code quality and detect potential bugs.
